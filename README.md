# Future Wells Kansas — Backend

Rust/Axum/sqlx ingestion + API backend for the Kansas oil & gas well SEO site, following the same architecture as the sibling Future Wells state backends (Wyoming, Oklahoma, North Dakota, New Mexico, Colorado).

Data sources: Kansas Geological Survey (KGS) for the well/production/field foundation, Kansas Corporation Commission (KCC) for operators, drilling intents, approved transfers, and conservation dockets. See `future_wells_kansas_backend_marketing_codex_tasks.md` for the full source baseline, architecture decisions, data contracts, and task queue, and `docs/architecture/kansas-source-boundary.md` for the fixed module boundaries.

## Local development

```bash
cp .env.example .env      # fill in DATABASE_URL
cargo run --bin future_wells_ks_api   # runs pending migrations, serves on :4008
cargo run --bin ks_ingest -- status   # database connectivity check
cargo run --bin ks_ingest -- sources  # list the official source registry
cargo test
```

Requires Postgres with the `postgis` and `pg_trgm` extensions available (a disposable dev instance: `podman run -e POSTGRES_PASSWORD=changeme -p 5432:5432 postgis/postgis:16-3.4`).
