Extraction-relevant observations:
- Image-only — no text layer at all (confirmed via `file`: a plain PDF
  wrapping a raster scan, no embedded font/text objects). Any automated
  pipeline needs real OCR (Tesseract or similar), not PDF text
  extraction, for this format.
- Contains zero directional-survey content of any kind — this is a
  vertical-well formation-tops/casing log from 1928, decades before
  directional drilling was practiced in Kansas. Its appearance in KGS's
  live `HorizWells` query result set (1,180 real records, confirmed live
  2026-09-06) is very likely a data-quality artifact in KGS's own
  classification (see main report) — a real, concrete example of why
  "estimated coverage" cannot simply take that query's row count at face
  value as "wells needing trajectory extraction."
- Real-world OCR risk factors visible in the source image: period
  typewriter font (inconsistent letter spacing), foxing/water staining
  obscuring some characters, a handwritten document-control number
  ("21284") in the corner, and an illegible rubber-stamp overlay — a
  realistic difficulty sample, not a clean modern scan.
